# 率失真：实验计划与现有证据

## 论文写什么，仿真做什么（2026-11-16）

工作一的定位是“理论 + 验证”。固定信源和失真后率失真函数唯一，流形分析给出的是对这个码率的刻画（内在维数、体积熵、曲率、知识增益、任务秩），不是比欧氏方案更低的码率。主稿引言已写明这一点，实验不设“流形方法胜过欧氏方法”的性能对比。

知识库记作 $\mathcal K=(\theta,K)$。下表划分每一项落在主稿的哪一层、仿真里用什么实现。主稿只出现左两列的对象和右列的实例化说明，划分、网格、斜率和运行细节留在本文件。

| 对象 | 主稿中的定义与结论（模型层） | 仿真中的实例（实现层） |
|---|---|---|
| 参数知识 $\theta$ | 预训练参考模型的权重、预测头和锚点字典；确定性，$I(U;\theta)=0$；它定义 $(\mathcal M,g,\mu)$。所有定理对固定 $\theta$ 成立 | 冻结的 ResNet-18 / MobileNetV3-Small 特征，8,192 张训练图上拟合并做温度校准的线性头，前 256 个训练 ID 作锚点。换骨干是换一个信源，只在标签损失这类外部判据下比较 |
| 情境知识 $K$ | 与 $X$ 联合分布、双方已知当前取值的随机变量；作为公共边信息，并可选择 $(\mathcal M_k,g_k,\mu_k)$。定理 2 的 $K$ | CIFAR-100 的粗类（20 值）和细类（100 值）标签。标签是“双方共享的场景信息”的替身，属于理想化设定，从不发送 |
| 知识增益 | $\Gamma_K\to I(U;K)-\tfrac12\mathbb E\ln\det(g_0^{-1}g_K)$；固定判据时 $0\le\Gamma_K\le I(U;K)$；嵌套知识的链式界 | 圆上四种情形核对完整公式（[framework_checks.py](framework_checks.py)）。真实特征只核对固定判据的界和嵌套界（[knowledge_cifar100.py](knowledge_cifar100.py)），因为度量项需要估计 $\det(g_0^{-1}g_K)$，尚未进行 |
| 流形 $\mathcal M$ 与 Assumption 1 | 光滑紧致流形、正连续密度，属建模假设 | 有限点云：采样状态等权、声明的锚点和代价矩阵。结论是这个有限问题的区间，不是总体信源的界 |
| 语义失真 | $d_{g_0}^2$、$d_{g_k}^2$、$\delta_T=D_{\rm KL}(q\Vert\hat q)$ | 单位特征的平方弦长；冻结细类头后验之间的 KL。头的后验是代理，不是真实 Bayes 后验 |
| 率失真函数 | $R_\delta(D\mid C)$ 及其高分辨率展开 | Blahut 迭代的可达点与对偶下界，报告 [下界, 上界] |

文本或多模态基础模型的对应做法相同：$\theta$ 取冻结的 LLM/MLLM，$U$ 取固定长度的连续表示（池化或末位隐状态；离散 token 序列本身不是流形上的点），$K$ 取检索条目、主题或对话上文，任务后验可直接取模型的下一词分布。这部分尚未实现，主稿不作声明。

**最先检验的主张。** 固定任务和观察时，强制“解码为一个能实现的对象”是否付出可测代价？要分别比较操作定义、有限源上下界和实际数字链路。网格 BA 上界不能充当全体连续重构的下界；拟合后验与真实 Bayes 后验也不能混称。

| 实验 | 自变量与对照 | 判据、已有材料 |
|---|---|---|
| 后验圆、条件源 | 圆上重构/圆盘网格、均匀/共享 K、不同网格 | 固定 D 给上下界而非单线。已有 [有限上下界](results/finite_rd_bounds.csv)、[零率](results/toy_zero_rate.csv)、[高斯链路](results/gaussian_link.csv) |
| 真实特征，经验源编码 | 固定任务头；嵌套比较 M 个训练对象和这 M 个对象加 M 个相邻锚点后验中点；改变 beta | 训练集输出目标上下界及 gap；未参与训练的数据上用冻结先验重新计算条件分布、实际边缘、I 和 KL。测试 I 不是训练问题的下界。“有限中点”不是“完整单纯形” |
| 实际比特及无线链路 | 固定宽索引；无噪声、单位能量 BPSK+AWGN、每索引一个相干 Rayleigh 增益；相同常规比特映射，无纠错/重传 | 实际使用次数、BER、索引 BLER、KL、准确率、真实标签 NLL。固定 2M 输出比 M 多一位；在相同带宽比较 2M 个对象与 M+M，须两次使用相同底层训练排列；在相同信息率时单独比较曲线 |
| 任务与模型失配 | 同模型余弦近邻、同模型 KL 近邻、直接发标签决策；另用同一 ID 所代表的异模型锚点解码 | [既有双模型预实验](results/semasia_cifar100.json)提供跨模型真实负对照。直接发送 20 类判决要 5 位；无效字样计为错误/擦除，无免费回退，硬判决不报伪造 KL |

**真实点云上的几何对照。** 除后验 KL，训练入口另有 `--criterion task_chord` 与 `--criterion graph_geodesic --neighbors 12`，均固定对象码本。前者在冻结的 `(2√q, √η u)` 坐标用平方弦长；后者在训练点构建带权并集 kNN 图，计算锚点的平方最短路。测试图只能挂到训练顶点，不参与训练图拓扑或相互连边。报告构图 k、连通性、成本单位和对 k=8/12/24 的敏感性；断图直接报错。比较弦长和图路径、以及下游 KL/标签风险是否一致；平方图长没有 bit 单位。[已运行的图测地近似](results/semasia_smoke_geodesic.json)和[相同锚点弦长对照](results/semasia_smoke_task_chord.json)使用相同 ResNet-18 短验证数据。正式矩阵同时覆盖这些判据。参见 [连续几何上下界与小失真推导](derivations/geometric_bounds.md) 和 [图实现](experiments/reference_graph.py)。

**数据与划分。** [SEMASIA 原论文](https://arxiv.org/abs/2605.09485)、[官方 CIFAR-100](https://huggingface.co/datasets/spaicom-lab/semasia-cifar100)。固定 revision `ace0aa91fc0b79953ec1ac619a25072d3a5b3037`，SHA-256 见 [读取器](experiments/semasia_io.py)。ResNet-18 512 维、MobileNetV3-Small 1024 维；每个模型单独按训练 ID 的稳定随机排列取 8192 个拟合、2048 个温度校准、首 M 个拟合 ID 作锚；验证用官方训练集余下 ID，测试只从官方 test 取样。拟合线性头使用原标签，但编码决策看测试特征预测，不看真标签。默认任务是 20 个粗类，100 个细类作任务敏感性比较。ID 键带 split，禁止把不同模型向量按行号或不同维坐标逐维相减。码本、头、知识预先共享；若要更新，另计描述开销。

**正式表格。** 两个模型，训练种子 1115/1116/1117，探查码字数 M=16/64/256（做严格等宽对照时另加 32/128/512 对象码本），beta=0.25/0.5/1/2/4/8。状态：控制住合法输出和双边上下界可复核有限圆例，真实数据的全矩阵尚未执行。对每个模型在共同 D 区间比较上下界/可达率，意外饱和时报告有限字母表、估计维数对尺度/子样本的敏感性。对同一测试 ID 的差按图像配对重采样；跨训练种子单列区间。不要把多次噪声或相同图像当成独立源样本。报告训练 gap 是否达到容差与运行时间；只对训练的有限离散问题使用“证书”。

**这次执行的例子。** [GPU 测试 JSON](results/semasia_smoke.json)：真实 ResNet-18，768 拟合/192 校准/192 官方测试，16 个锚和 beta=3。训练 Lagrangian 对偶间隙约 0.00000683 bit；独立测试的经验信息率 2.739 bit/图，实际发送 4 个 BPSK 符号/图。二者用途不同。[第二模型与扩充字母表](results/semasia_smoke_augmented_mobile.json)用于检查另一条代码路径，两项改变同时发生，不能比较算法优劣。旧版较大预实验用 8192/2048/2048，256 锚点下的真实准确率应与更便宜的直接标签判决比较。JSON 与逐图 .npz 只作复现实例，不是正式多种子结论。

## 真实特征上的共享知识增益（2026-11-16）

`knowledge_cifar100.py` 依赖 NumPy、SciPy、scikit-learn、pyarrow，不需要 PyTorch 和 GPU，本机约 8 分钟。输出 [knowledge_cifar100.json](results/knowledge_cifar100.json) 与主稿表 `tab:kreal`。命令：`python knowledge_cifar100.py --data data/semasia --download`。

**设置。** 每个骨干单独处理。训练集取 8,192 张拟合 100 类线性头、2,048 张拟合温度，前 256 个拟合 ID 作锚点；信源是 8,192 张官方测试图的等权点云（种子 20261116）。两种代价：单位特征的平方弦长；细类头后验之间的 KL（bit）。三种知识条件使用相同的信源状态、锚点和代价：无知识、共享粗类、共享细类。任务代价下细类就是任务变量，只共享粗类。每个问题扫 28 个斜率，在“无知识码率等于 0.5–6 bit”的失真处给出 [对偶下界, 时分上界]。全部问题的拉格朗日对偶间隙不超过 $1.6\times10^{-6}$ bit。

**结果。** 增益 $R(D)-R(D\mid K)$ 的区间（bit）：

| 骨干 | 无知识码率 | 弦长，粗类 | 弦长，细类 | 后验 KL，粗类 |
|---|---:|---|---|---|
| ResNet-18 | 2 | [1.59, 1.62] | [1.98, 2.00] | [1.90, 1.95] |
| | 4 | [2.10, 2.16] | [2.95, 3.00] | [2.75, 2.78] |
| | 6 | [2.27, 2.32] | [3.34, 3.37] | [3.00, 3.04] |
| MobileNetV3-S | 2 | [1.53, 1.58] | [1.96, 2.00] | [1.86, 1.88] |
| | 4 | [2.10, 2.16] | [2.99, 3.04] | [2.73, 2.76] |
| | 6 | [2.30, 2.32] | [3.39, 3.43] | [3.03, 3.07] |

- 所有区间落在 $[0,\min\{R,H(K)\}]$ 内，$H(K)$ 为 4.32（粗类）和 6.64 bit（细类）。嵌套界成立：给定粗类的码率比给定细类的码率最多高 1.11 bit，上限 $H(K_2\mid K_1)=2.32$ bit。
- 增益随失真减小而增大，但远未达到 $I(U;K)$。256 个锚点下失真很粗：ResNet-18 的平方弦长从零码率的 0.65 只降到 6 bit 处的 0.42。
- 低码率下知识可以替代消息：无知识码率为 1 bit 时，增益至少 0.96 bit。
- 两个骨干的零码率失真不同（0.65 与 1.04），相同码率处的增益相差不到 0.1 bit。
- 细类头的测试准确率为 61.58% 和 64.51%；留出分类器给出总体 $I(U;K_{\rm coarse})$ 的下界 3.09 和 3.14 bit。

**这项实验没有说明什么。** 标签作为共享知识是理想化设定，部署时的情境知识会有误差。结论是这个有限问题（等权样本、256 个锚点、给定代价）的证书，不是总体信源的界；每个细类条件只有 70–100 个样本。判据固定，所以增益公式里的度量项没有被检验。只有一个随机种子。

## 针对外部审阅意见的修补（2026-11-18）

逐条判断见下表。处理方式只有三种：补推导、补验证、删主张。

| 审阅意见 | 判断 | 处理 |
|---|---|---|
| 附录 B 曲率项的可达性推导符号有误，非均匀源可能多出 Fisher 信息项 | 推导正确，但中间步骤过简，且非均匀密度从未做过数值核对 | 主稿把 $I_t=-tD_t-\mathbb E\ln(T_tp)(U)-D_{\rm KL}(p_A\Vert p)$ 展开写出；新增 $S^2$ 上倾斜密度的精确核对（下） |
| 命题 2 把 $D\ll\eta$ 的展开外推到 $D\gg\eta$ | 成立 | 新增非渐近界 $R_T(D)\le R_\eta(D)\le R_T(D-\eta\Delta_k^2)$，两个区间分开陈述 |
| 定理 5 需要 $d_J<\tau^2$ 几乎必然成立 | 成立 | 对 $d_J\ge\tau^2$ 的消息用 $\|m_J-b_J\|^2\le v_J\le d_J\le d_J^2/\tau^2$，去掉该条件，结论不变 |
| 用“硬胞元”命题解释软测试信道 | 命题对任意集中的条件分布成立，措辞有误导 | 改为“给定消息的条件分布”。等信息间隙趋于混合曲率常数仍是数值观察：证明需要 KL 代价下两个率失真函数到 $o(D)$ 的展开，尚未完成，主稿已写明缺什么 |
| 真实数据没有验证秩律 | 成立 | 新增真实后验点云上的秩律实验（下） |
| 真实数据没有验证度量项 | 成立 | 没有找到自然的真实实例，不做；主稿保留“未检验”的说明 |

**$S^2$ 上非均匀密度的曲率系数。** `framework_checks.py` 的 `nonuniform_sphere`：密度 $p\propto1+a\cos\theta$，用 Legendre 系数（Funk–Hecke）精确计算源加权 Gibbs 核的 $(D_t,I_t)$ 和对偶下界。$a=0.8$（Fisher 信息 0.506）时，归一化余量在 $D=0.0100$ 为 0.16679（上）和 0.16678（下），在 $D=0.0033$ 均为 0.16671，理论值 $1/6$。若存在 Fisher 项，系数应为 0.293。

**真实后验点云上的秩律。** `rank_cifar100.py`。把 20 个粗类随机并成 $c=2,3,4$ 组（各 2 种划分），每个骨干拟合校准的 $c$ 类头，取 $n$ 个测试后验的等权点云作信源，对象接收机，KL 代价，16 个斜率。只在 $n$ 与 $n/2$ 两条曲线相差不超过 0.05 bit 的范围内读斜率，报告该范围较细一半上的值（bit/失真减半）：

|---|---:|---|---|
| 1 | 0.5 | 0.497–0.498 | 0.499–0.500 |
| 2 | 1.0 | 0.935–0.947 | 0.957–0.964 |
| 3 | 1.5 | 1.139–1.183 | 1.217–1.268 |

## 第二轮审阅后的修补（2026-11-19）

- **因子 2。** 坐标 $(2\sqrt q,\sqrt{w}\,u)$ 的平方弦长是 $G_q+w\,g_0$，即联合度量 $\tfrac12G_q+\eta g_0$ 在 $\eta=w/2$ 时的 2 倍。等距亏量对整体缩放不变，已有数值全部有效，只是此前标的 $\eta=0.1$ 实际是 $\eta=0.05$。主稿已改为 $z=(2\sqrt q,\sqrt{2\eta}u)$ 并注明“两倍”。
- **一般失真的假设。** 原条件允许失真在半径内远离对角线处为零。现要求 $c_0\epsilon_0\le\tfrac12$，于是半径内 $\delta\ge\tfrac12d_g^2$。平方测地失真的结果不受影响。
- 条件分配 $D_k=Dm_k/\bar m$ 注明为一阶最优。
- **变曲率曲面上的曲率项。** `framework_checks.py` 的 `spheroid`：半轴 $(1,1,0.7)$ 的扁椭球，高斯曲率从两极 0.49 到赤道 2.04。每个基点在测地极坐标下积分核：RK4 打靶测地线，体积元由 Jacobi 方程 $J''=-KJ$ 给出（球面上复现 1/6，Gauss–Bonnet 积分为 1 到 $10^{-9}$）。密度偏向两极 $p\propto1+3(z/c)^2$ 时，$D=10^{-3}$ 处可达核与对偶下界的归一化余量为 0.17020、0.17013，预测 $\mathbb E_p[\mathrm{Scal}]/12=0.17022$；偏向赤道 $p\propto1-0.9(z/c)^2$ 时为 0.24063、0.24049，预测 0.24058。曲率的面积平均对两者都给出 0.20646。系数确实是按信源密度加权的平均曲率。
