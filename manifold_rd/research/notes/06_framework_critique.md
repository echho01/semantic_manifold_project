# 对 Word 与开题 PPT 的批判性对照：哪些能用、哪些要改、主线怎么定

2026-11-16 整理。对象是[老师的 Word](../../../../语义通信的语义流形理论.docx)（十二部分）与[开题报告](../../../../高凡-开题报告-1114.pptx)第 10、15–27 页。目标是研究内容一"基于流形的语义率失真"：广义、知识库条件、任务导向三层率失真。修正后的推导见 [framework.md](../derivations/framework.md)，主稿见 [main.tex](../../main.tex)。

## 一　结论

三层率失真可以严格推出，而且是同一个定理在不同（流形、度量、概率）下的实例。Word 提供了直觉和问题清单，其中的"定理"大多不能直接用；PPT 的定义基本正确，缺的是定理、三者之间的比较和若干前提。

| 层 | 广义 | 知识库 | 任务 |
|---|---|---|---|
| 流形建模 | $(\mathcal M,g_0,p)$，假设 1 | $K$ 改变概率、度量或支撑 | 后验头 $q_t$，任务秩 $r$ |
| 语义失真 | $d_{g_0}^2$ | $d_{g_K}^2$，校准 $a g_0\preceq g_K\preceq b g_0$ | $D_{\rm KL}$，局部 $\tfrac12 v^\top G_q v$；联合 $\tfrac12G_q+\eta g_K$ |
| 语义率失真 | $h_g-\tfrac m2\ln\frac{2\pi eD}m+\frac{\overline{\rm Scal}}{6m}D$ | 增益 $\to I(U;K)-\tfrac12\mathbb E\ln\det(g_0^{-1}g_K)$ | $h_F-\tfrac r2\ln\frac{4\pi eD}r$，相对广义节省 $\tfrac{m-r}2\ln\frac1D$ |

## 二　Word 逐条

| Word 的说法 | 判断 | 主稿中的处理 |
|---|---|---|
| 二、三：语义等价关系的商空间是光滑流形 | 不成立。商空间成为流形需要常秩等条件，一般只是分层空间 | 流形作为可检验的假设 1；任务商 $\mathcal S=q(\mathcal M)$ 要求常秩；多分支或变维数用上下文索引各层 |
| 三（四）：语义失真 = 点到流形的距离 | 不能作失真。流形上两个不同语义之间该量恒为零（猫误为狗） | 失真定义为两点间的 $d_g^2$。点到流形的距离只度量法向扰动，投影后剩切向 $m\sigma^2$（命题 1(iii)） |
| 四：IB 最优表示必然是低维光滑流形（"定理"） | 不成立。IB 最优表示可以离散；"满维则率无界"、"编码器连续故光滑"都不是证明 | 保留其中正确的一点：对数损失下预测接收机的率失真就是 IB 曲线（定理 4 之后）。流形不由 IB 推出 |
| 六：语义层分离定理失效，JSCC 最优、分离次优 | 不成立。分离定理对任意加性失真（含流形距离）在长码下成立。JSCC 的优势在有限码长、平滑退化和未知信道 | 命题 6：分离给出极限与指数 $2\kappa/r$；一次性模拟映射指数为 1，仅在 $2\kappa=r$ 时匹配。结论与 Word 相反且定量 |
| 六（五）：噪声小于曲率半径则 JSCC 失真有界、分离无界 | 不是定理 | 命题 1 给出局部失真的精确形式及其失效条件（噪声与 reach 可比时比值 1.47） |
| 七：注意力 = 热核/测地插值，LayerNorm ⇒ 等距嵌入，前向扩散 = 流形上的热方程，得分 = 法向量场 | 类比。前向扩散在环境空间进行；得分近似法向只在小噪声极限成立；"发送纯噪声 $x_T$"不携带信息 | 不作为前提。只在相关工作中引用已证明的结果（扩散模型编码内在维数） |
| 八：知识库 = 度量张量，任务 = 切空间投影 | 概念可用，但前后不一致：先说知识只改距离不改点，后说知识折叠维度 | 知识的三种作用分开：改概率、改度量、改支撑，各自的码率效应不同（定理 2） |
| 十、十一：信道增益写进语义率失真；深衰落使率失真发散；噪声趋零则率失真趋零；语义注水 | 混淆了信源函数与信道。信源率失真与信道无关；衰落改变容量和给定接收机的失真 | 信道只通过容量（命题 6，含中断）和诱导失真（命题 1）进入。源侧"注水"在高分辨率下就是度量本身：误差协方差 $(D/m)G^{-1}$ |
| 十一（三）：无 CSI 时由 Jensen 得率失真严格更大 | 论证方向不成立，且对象错了 | 遍历与准静态两种信道模型分别给出逆定理 |
| 十二 定理 1：$K_1\subset K_2\Rightarrow R_{K_2}\le R_{K_1}$ | 一般不成立。固定知识库不是随机变量，$I(S;\hat S\mid K)$ 的条件化无内容；知识把度量变细时码率上升 | 定理 2(iii)(iv) 给出成立条件：固定判据下的公共边信息，或只把度量变粗。反例：增益 −0.276 bit |
| 十二 定理 2：$R_T\le R$ | 不同失真单位不可比 | 引理 1 的校准常数 $L_T$；$R_T(D)\le R_0(D/L_T^2)$ 对一切 $D$ 成立（定理 3） |
| 十二 定理 3：联合率失真的"和式上界" | 未证明，一般不成立 | 命题 2：对一切 $D$ 成立的夹逼与高分辨率精确式 |
| 十二（八）：CSRD-BA 把信道转移概率放进率失真迭代 | 目标函数是端到端失真优化，不是率失真函数；收敛性陈述只适用于标准 BA | 有限字母表上用标准 BA 加对偶证书（第 VIII 节）；链路单独记账 |

## 四　主线的取舍

上一版主稿以"对象接收机与预测接收机"为主线。比较两种组织方式：

| | 以三层率失真为主线 | 以接收机字母表为主线 |
|---|---|---|
| 回答的问题 | 语义保真要多少比特；知识和任务各省多少 | 接收端必须返回可实现对象时多付多少 |
| 与开题的关系 | 对应第 18–21、23 页 | 只对应第 20 页 $d_T$ 定义里的一个隐含选择 |
| 新结论的分量 | 曲率项、知识增益分解及反例、任务秩律、联合判据的夹逼 | 凸性刻画、二次下界、reach 上界、混合曲率常数 |
| 实际量级 | 一阶效应（斜率、常数） | 二阶小量，$O(D^2)$ |
| 主要弱点 | 高分辨率渐近，与低码率工作点有距离；各实例单独看接近已有高分辨率理论的推论 | 面窄，撑不起"语义率失真理论" |

采用三层率失真为主线，接收机字母表作为其中一层保留。针对主线的弱点：每个渐近结论都配了对任意 $D$ 成立的版本（Gibbs 上下界、度量支配序、公共边信息界、联合判据夹逼、有限字母表证书），并在讨论中说明渐近式的用途是指出支配码率的量。

## 五　仍然开放的问题

- 曲率项要求光滑正密度与无边界；有边界、分层或密度趋零的情形未处理。
- 等信息间隙收敛到混合曲率常数是数值证据，缺最优编码器胞元失真渐近相等的证明。
- 真实特征上尚无三层率失真的测量：需要内在维数、Fisher 拉回秩与体积熵的估计及其不确定度，SEMASIA 全矩阵未执行。
- 单侧知识（只有接收端知道 $K$）是 Wyner–Ziv 问题，知识库同步的传输代价也未计入。
